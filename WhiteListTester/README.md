# WhiteList Tester

Приложение для Android, предназначенное для тестирования работы интернета в режиме "Белых списков" (ограниченного доступа к ресурсам). Помогает определить, работает ли у вас полный доступ ко всем сайтам или только к российским сервисам из утвержденного перечня.

## Возможности

- **Автоматическое определение статуса сети:**
  - 🟢 **Интернет работает нормально** — доступны как российские, так и зарубежные сайты.
  - 🟠 **Режим: Белые списки** — работают только российские сервисы (VK, Яндекс), зарубежные заблокированы.
  - 🔴 **Нет соединения** — проблемы с подключением к интернету.
  - 🟡 **Нестабильное соединение** — часть сервисов недоступна.

- **Оптимизированная проверка:** Тестирование занимает всего 3–5 секунд благодаря параллельной проверке ключевых узлов.
- **Современный дизайн:** Интерфейс выполнен в стиле **Liquid Glass** с анимированными градиентами и эффектом матового стекла.

## Проверяемые ресурсы

Приложение проверяет доступность следующих ресурсов:
- **Белый список (российские сервисы):** VK.ru, Ya.ru
- **Внешние сайты (для сравнения):** Google.com

*Для сравнения также проверяется доступность зарубежных ресурсов (Google).*

## Требования

- Android 8.0 (API 26) и выше.
- Разрешение на доступ к интернету (выдается при установке).

## Установка и запуск

### Вариант 1: Сборка из исходного кода (рекомендуется)

1. Откройте проект в **Android Studio**.
2. Дождитесь завершения синхронизации Gradle.
3. Подключите устройство или запустите эмулятор.
4. Нажмите кнопку **Run** (зеленый треугольник) или используйте комбинацию `Shift + F10`.

### Вариант 2: Сборка APK файла вручную

Если вы хотите получить установочный файл:
1. В меню выберите **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**.
2. После завершения сборки нажмите **locate** в появившемся уведомлении.
3. Файл `app-debug.apk` будет находиться в папке `app/build/outputs/apk/debug/`.
4. Передайте файл на устройство и установите его.

> **Примечание:** Для сборки релизной версии (без отладки) используйте **Generate Signed Bundle / APK**, предварительно создав ключ подписи (Keystore).

## Структура проекта

- `MainActivity.kt` — основная логика проверки сетей и управления интерфейсом.
- `activity_main.xml` — разметка экрана в стиле Liquid Glass.
- `AndroidManifest.xml` — конфигурация прав доступа и компонентов приложения.
- `build.gradle` — настройки зависимостей и компиляции.

## Технологии

- **Язык:** Kotlin
- **UI:** XML, CardView, Material Design элементы
- **Асинхронность:** Kotlin Coroutines для неблокирующей проверки сети
- **Минимальная версия SDK:** 26 (Android 8.0)
