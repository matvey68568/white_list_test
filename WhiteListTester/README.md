# White List Tester - Приложение для тестирования российских белых списков

## Описание
Приложение для Android, которое проверяет доступность сайтов из российского белого списка и внешних ресурсов для определения текущего статуса интернет-соединения.

## Статусы
1. **Интернет работает нормально** - когда открываются все сайты (не только из белых списков)
2. **Белые списки** - когда работают сайты только из белых списков
3. **Нет соединения** - когда не работает ни один сайт

## Список проверяемых сайтов

### Сайты из белого списка:
- **Государственные компании и сервисы**: Госуслуги, Россети, Московская биржа, сайты Госдумы, Правительства, Генпрокуратуры
- **Маркетплейсы**: Ozon, Wildberries
- **Кафе и рестораны**: Додо Пицца, Вкусно — и точка
- **Связь**: Билайн, МегаФон, МТС, Ростелеком, T2
- **Сервисы для путешествий**: Аэрофлот, РЖД, Победа
- **Банки**: Газпромбанк, Альфа-Банк, платёжная система Мир
- **Гипермаркеты и магазины**: Лента, Окей, ВкусВилл, Ашан, Metro
- **Каршеринг и такси**: Яндекс Go, Делимобиль, Ситидрайв
- **IT-компании**: 1С, Труконф
- **Медиа и социальные сети**: Аргументы и факты, Первый канал, ВКонтакте, Одноклассники, Mail.ru, Дзен, Rutube

### Внешние сайты (для проверки):
- Google, YouTube, Instagram, Facebook, Twitter

## Требования
- Android SDK 21+ (Android 5.0 Lollipop)
- Android Studio Arctic Fox или новее
- Gradle 8.0

## Установка
1. Откройте проект в Android Studio
2. Настройте `local.properties` с путем к вашему Android SDK
3. Соберите проект: Build → Make Project
4. Запустите на эмуляторе или реальном устройстве

## Использование
1. Запустите приложение
2. Нажмите кнопку "Начать тестирование"
3. Дождитесь результатов проверки
4. Приложение отобразит текущий статус интернет-соединения

## Разрешения
- `INTERNET` - доступ к интернету для проверки сайтов
- `ACCESS_NETWORK_STATE` - проверка состояния сети
