# WhiteList Tester

Приложение для Android, предназначенное для тестирования работы интернета в режиме "Белых списков" (ограниченного доступа к ресурсам). Помогает определить, работает ли у вас полный доступ ко всем сайтам или только к российским сервисам из утвержденного перечня.

## Возможности

- **Автоматическое определение статуса сети:**
  - 🟢 **Интернет работает нормально** — доступны как российские, так и зарубежные сайты.
  - 🟠 **Режим: Белые списки** — работают только российские сервисы (Госуслуги, Яндекс, Rutube и т.д.), зарубежные заблокированы.
  - 🔴 **Нет соединения** — проблемы с подключением к интернету.
  - 🟡 **Нестабильное соединение** — часть сервисов недоступна.

- **Оптимизированная проверка:** Тестирование занимает всего 3–5 секунд благодаря параллельной проверке ключевых узлов.

- **Наглядный результат:** После теста отображается список всех проверяемых сайтов со статусом доступа:
  - ✓ — сайт доступен
  - ✗ — сайт недоступен

## Проверяемые ресурсы

Приложение проверяет доступность следующих ресурсов:
- **Белые списки (российские сервисы):** yandex.ru, yandex.ru/maps, rutube.ru, gosuslugi.ru
- **Внешние сайты:** google.com

## Требования

- Android 8.0 (API 26) и выше.
- Разрешение на доступ к интернету (выдается при установке).

## Установка и запуск

1. Скачайте последний APK-файл из вкладки **Releases**.
2. Передайте файл на устройство и установите его (может потребоваться разрешение на установку из неизвестных источников).
3. Запустите приложение и нажмите кнопку для проверки соединения.

## Структура проекта

- `MainActivity.kt` — основная логика проверки сетей, управления интерфейсом и отображения результатов теста.
- `activity_main.xml` — разметка экрана приложения со списком сайтов.
- `item_site.xml` — разметка элемента списка для отображения сайта со статусом (✓/✗).
- `AndroidManifest.xml` — конфигурация прав доступа и компонентов приложения.
- `build.gradle` — настройки зависимостей и компиляции (версия приложения: 1.1).

## Технологии

- **Язык:** Kotlin
- **UI:** XML, CardView
- **Асинхронность:** Kotlin Coroutines для неблокирующей проверки сети
- **Минимальная версия SDK:** 26 (Android 8.0)
